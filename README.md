이 저장소는 0.4.2까지 Waitscape 설치 파일을 올리던 곳이에요. 지금은 소스 코드 저장소 [jhkwim/waitscape](https://github.com/jhkwim/waitscape)에서 설치 파일·업데이트를 함께 배포해요. 이 저장소는 보관(읽기 전용)되어 더 이상 갱신하지 않아요.
This repository hosted Waitscape installers up to 0.4.2. Installers and updates now ship from the source repository [jhkwim/waitscape](https://github.com/jhkwim/waitscape). This repository is archived (read-only).

## 옛 버전을 쓰고 있다면 / If you run an older version

- **0.3.0 ~ 0.4.1**: 앱의 🎁 업데이트 알림을 누르면 돼요. 새 위치로 자동으로 넘어가요.
  Click the 🎁 update notice in the app; it moves to the new location automatically.
- **0.3.0보다 오래된 버전 / older than 0.3.0**: [최신 설치 파일](https://github.com/jhkwim/waitscape/releases/latest)을 받아 그대로 덮어 설치하세요(데이터는 그대로).
  Download the [latest installer](https://github.com/jhkwim/waitscape/releases/latest) and install over it (your data is kept).
